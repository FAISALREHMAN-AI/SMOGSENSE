# 🌫️ SmogSense AI — Lahore Air Quality Dashboard

**An interactive air-quality monitoring and machine-learning dashboard for Lahore, Pakistan.**

🚀 **[Launch Live Dashboard](https://smogsense-ai.streamlit.app/)** | 💻 **[View Source Code](https://github.com/FAISALREHMAN-AI/SMOGSENSE)**

## ✨ Features

- 📊 Interactive air-quality dashboard and AQI gauge
- 📈 Visual analytics and interactive charts
- 🤖 Machine-learning-based air-quality prediction
- 🔮 Forecast visualization
- 🎛️ Interactive what-if simulator
- 🧭 Eight dashboard navigation sections
- 📱 Responsive interface for smaller screens

## 🛠️ Tech Stack

- **Language:** Python
- **Dashboard:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Visualization:** Altair and Matplotlib
- **Machine Learning:** Scikit-learn
- **Deployment:** Streamlit Community Cloud
